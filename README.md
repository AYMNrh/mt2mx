## Important status

**This is a complete, structurally validated baseline—not production-approved CBPR+ translation logic.**

The applicable CBPR+ Usage Guidelines and SWIFT Translation Library were not available. Consequently:

- every implementation candidate remains `REVIEW_REQUIRED_CBPR`;
- uncertain relationships are labeled conditional rather than guessed;
- the source register records both missing artifacts as blocking evidence;
- the user-confirmed source PDFs are included under `sources/official/`; extracted text and private XSD copies remain outside the repository.

## Runtime translator

`mt2mx.runtime` implements the baseline as executable code:

```python
from mt2mx.runtime.builder import translate

result = translate("""{1:F01BANKBEBBAXXX0000000000}{2:I103BANKDEFFXXXXN}{4:
:20:TRX98765
:23B:CRED
:32A:260712EUR2500,00
:50K:/DE89370400440532013000
JOHN DOE
:52A:DEUTDEFF
:57A:CHASUS33
:59:/GB29NWBK60161331926819
ACME TRADING LTD
:71A:SHA
-}""")
result.mx_message_id   # 'pacs.008.001.08'
result.xml             # schema-valid XML bytes
result.warnings        # every assumption and synthesis
```

Current translation test state (regenerated by `scripts/run_review.py`):

- **6/6 samples produce schema-valid XML** against the exact private XSDs.
- **61 field mappings** exercised, **4 documented skips** (71F/71G charge details require an agent MT cannot supply; 23E/77B/13C partial handling is flagged), **0 present-but-unmapped fields**.
- **31 tests** cover parsing, transforms, building, and XSD validation.

Synthesized values (schema-mandatory, absent from MT, always warned):
`SttlmMtd=CLRG`, header BIC fallbacks, `Sts=BOOK` and `BkTxCd=M910`

`AcctOwnr` from sender BIC (camt.060).

## Evidence grades

- **B:** strong base-standard semantic alignment, often independently corroborated, but not SWIFT-translation approved.
- **C:** plausible conditional mapping requiring rule/profile confirmation.
- **D:** ambiguous relationship or context-sensitive selection requiring explicit SME decision.

No row is grade A because no applicable official translation-rule export was available.

## Rebuild locally

The committed outputs are viewable without rebuilding. Rebuilding requires the PDFs in `sources/official/`, private XSD copies, and the existing DFR mapping:

```bash
uv sync --extra build --extra runtime --extra test
uv run python scripts/build.py \
  --pdf-dir "sources/official" \
  --text-dir ".private/extracted" \
  --xsd-dir ".private/schemas" \
  --dfr-csv "C:/path/to/ALL_SOURCE_TO_TABLES.csv"
uv run python scripts/run_review.py
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 uv run pytest -q
uv run python scripts/verify.py
```

`pdftotext` must be installed for fresh PDF extraction.

## Publication boundary

Do not commit:

- extracted full text;
- licensed MyStandards/Translation Library exports;
- private XSD copies;
- confidential payment samples.

The repository includes the user-confirmed source PDFs under `sources/official/`, plus code, hashes, concise factual inventories, derived candidate rules, DFR lineage, and review documentation. CBPR+ Usage Guidelines and SWIFT Translation Library rules remain unavailable and the result is not production-approved CBPR+ logic.
